How to customise displayed timezones

The intention is that you customise the timezones to suit your needs and then save the corresponding URL / set it as a bookmark:

  • Set timezones to display: Add ?tz= to the URL with comma-separated timezone names or UTC offsets
    • Named timezones: Use IANA timezone names like Europe/London, America/New_York, Asia/Tokyo
    • UTC offsets: Use numeric offsets like 0, +4, -5, -8 to display fixed UTC offsets (eg. UTC+4, UTC-5)
  • Custom labels: Add :CustomName after any timezone to override the default location name

Examples:

  • ?tz=Europe/London,America/New_York,America/Los_Angeles
  • ?tz=Europe/London,America/Chicago,America/Los_Angeles:San Francisco
  • ?tz=Europe/London:UK,America/New_York:NYC,America/Los_Angeles:SF
  • ?tz=0,+4,-5,-8 (displays as UTC+0, UTC+4, UTC-5, UTC-8)
  • ?tz=Europe/London,+4:Dubai,-8:Pacific (mix named timezones and offsets)
